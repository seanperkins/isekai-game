Isekai Chronicles — the bestiary

Every creature at game scale, side by side, with the shapes the game uses for it. Sprites are the real sheet frames; the shapes are read from the same sheet data the game loads, so what you see here is what collides.

· design review · data: assets/sheets/*.json via tools/build_bestiary.py

Terrain body (dashed blue): the box that walks into walls and floors. Every enemy has the same 16×12 one, whatever it looks like.
Player body (dashed gold): 28×24, shared by every playable species and form.
Hurt shape (green): where it can be hit, and what hurts you on contact. Traced from the art, per frame.
Attack shape (red): the part that hits during an attack frame (a tackle, a charge, a dive). Only some frames have one.

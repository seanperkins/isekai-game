2. **[P1] Sticky Thread loses its spider hint.** Spec 1 removes thread essence and unlocks Sticky Thread from `PREDATED` family tags. The level-2 creature hint path iterates only `d.essences_used()` and raises a name only when `c.essences.has(ess)` ([compendium_model.gd](/Users/sean/sites/isekai-game/scripts/compendium/compendium_model.gd:160)); `essences_used()` reads only `ABSORBED` conditions ([skill_def.gd](/Users/sean/sites/isekai-game/scripts/skills/skill_def.gd:50)). Appraising a Black Spider before eating three spiders will no longer hint Sticky Thread. Add a family-based hint path.

3. **[P1] The listed test changes cannot yield a passing suite.** Spec 1 removes `FormOffers.supply` and `FIRST_EVOLUTION_AREAS`, but [test_first_evolution_areas.gd](/Users/sean/sites/isekai-game/tests/test_first_evolution_areas.gd:24) calls `FormOffers.supply(...)` and [line 34](/Users/sean/sites/isekai-game/tests/test_first_evolution_areas.gd:34) references the constant. Account for editor Play: [game.gd](/Users/sean/sites/isekai-game/scripts/game.gd:54) deliberately uses fresh in-memory progress there, so its form evolutions must not enter the real profile.

Define nested validation and warning behavior in FormLog and test that input.

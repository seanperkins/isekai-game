# The Deep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the fourth area: three creatures (and a rare one in a slice) with a shared pack alert, an unarmored charger and a ground stomp, the Tremor skill, five rooms (and one more in the slice) entered from the Flooded's marsh hall, and the third real rebirth kit.

**Architecture:** No new Kind and no new player physics. Three `CreatureDef` flags (`pack`, `charges`, `stomper`) widen the existing charger and `_sense`; Tremor is a Jolt-sized ability using `Ability.targets_around` and `receive_hit`'s existing `ignore_def`; the rooms are authored by a one-shot script through `RoomEditModel` and saved as `.tres`; the kit tests become one table-driven loop.

**Tech Stack:** Godot 4.7, GDScript, GUT 9.7.1 (`tools/run_tests.sh [substr]`), Python art tools run with `uv` (Codex image generation).

**Spec:** `docs/superpowers/specs/2026-10-01-the-deep-design.md` (approved after three debate rounds and a verification pass). Read it with this plan: the plan implements it task by task.

## Global Constraints

Copied from the spec; every task's requirements include them.

- Godot 4.7 / GDScript / GUT 9.7.1. Every new `class_name` script needs `env HOME="$PWD/.tmp/gdhome" godot --headless --import` and its `.uid` file committed. A SCRIPT ERROR or Parse Error fails the run. A full run takes minutes: use `TEST_TIMEOUT=900 tools/run_tests.sh` for the whole suite, a substring argument for a subset.
- Creatures (base numbers; the generator scales HP/ATK/DEF with `_at_level(DEEP_LEVEL)`, `DEEP_LEVEL = 10`, `_scaled` = +8% a level, rounded half up): Gloom Wolf 6/3/0/100 sound 1 earth 1 XP 6 (`charges`, `pack`); Armed Ant 5/2/1/90 armor 1 earth 1 XP 3 (`pack`); Stone Drake 16/4/3/40 earth 3 armor 1 XP 12 (`armored_charger`, `stomper`); Taratect (slice) 14/5/1/120 thread 3 poison 2 XP 12 (the spider's skills). Derived numbers: wolf HP 10 ATK 5 DEF 0; ant 9/3/2; drake 28/7/5; taratect 24/9/2. First-time value is `2 × xp`.
- `CreatureDef` gains `pack`, `charges`, `stomper` (default false). No new Kind: `_resolve_kind`'s CHARGER arm is `def.armored_charger or def.charges`.
- Pack: `PACK_RADIUS` 240. Only sight calls `_share_alert`; it sets `_alert = ALERT_MEMORY` on every other `Enemy` in the `actors` group with `def.pack` and the same `def.id` within the radius (`n is Enemy and n != self and n.def.pack and n.def.id == def.id`).
- Stomp (inside `_charger_act`, which gains the `player` argument): `STOMP_RANGE` 110, `STOMP_LEVEL` 40 (one zone for the trigger and the hit), `STOMP_WINDUP` 0.7, `STOMP_REST` 1.4. Trigger: alerted and `absf(dx) <= STOMP_RANGE` and `absf(dy) <= STOMP_LEVEL` (no forward-only test). The slam at the windup's end hits `receive_hit(atk, "physical", position)` only if the player is in the zone and `player.has_method("is_on_floor") and player.is_on_floor()`. The windup and rest are the charger's tokens; the drake's `rest` shows its `stomp` pose.
- Tremor: essence skill, absorb `earth` ×24 (a test pins it above the earth units the pre-Deep rooms hold: 22), active 5 MP, used ×8 per level, max 5, values 3/4/5/6/7 through `Damage.skill_power(value, ATK)`. Radius 72 (centre to centre), kept targets are `Enemy` and `is_on_floor()`; `receive_hit(power, "physical", from, "other", true)`; `if t.def.predatable: t.status.stun(1.0)`. No caster condition; never hurts the caster.
- Rooms (cells, sizes): D1 Gloom Gate (17,6) 1×1; D2 Wolf Run (18,6) 2×1; D3 the Sinkhole (20,6) 1×2; D4 the Den (21,7) 2×1; D5 the Heart (23,7) 1×1; slice D6 the Hollow (19,5) 1×1. F4's east exit meets D1's west at local y 240–320 (`to == 320`, both halves). D3's west door (from D2) is at D3 local y 240–320 with a ledge flush with the west wall at y 320 and a chain of ≤ 55 px hops to the floor (680). F4's ledge `Rect2(1120, 266, 100, 12)` is trimmed to `Rect2(1120, 266, 76, 12)`, F4's fourth lizardman (near x 1235) and the flowers decor (near x 1230) move west, so the Flooded's first pass stays 188.
- Pacing: the first-time sum over F1–F5 plus D1–D5 is at least 403 (`Progression.stage_total(2)`); the guide is D1 3 ants (18), D2 3 wolves and 3 ants (54), D3 1 drake and 3 ants (42), D4 4 wolves and 1 drake (72), D5 1 drake and 2 wolves (48) = 234, and 188 + 234 = 422.
- Rebirth: D1's pool id `D1`, area `deep`, kit skills `leap`, `wall_cling`, `swim`, `tremor`, level 5, seeds computed once and stored. The kit tests are one table.
- Process: TDD with a failing run first; no attribution lines in commit messages; report only commit SHAs copied from git output; relative paths with a `./` prefix when giving paths to the user; scratch under `.tmp/`.

## Review Focus

The input classes the plan's task tests would not exercise unless asked. Each has a test in the task that owns the code.

1. **The `actors` group holds more than enemies, and a pack that wakes onward.** The player, the shortcut switch and test stubs sit in `actors` and have no `def`; a woken packmate must never wake another. Expect: no error with a non-enemy in the group, no chain, and the mate calms ALERT_MEMORY after its finder loses sight (Task 3).
2. **A jump, a leave-the-zone and a stun during the drake's windup.** Expect: the slam misses an airborne player, one outside the zone (across or up), and nothing happens when the drake is stunned mid-windup; a stomper never enters `charge` (Task 4).
3. **Tremor on things that are not ordinary enemies.** The shortcut switch (a four-argument `receive_hit`), the serpent (not predatable), a stunned bat that has landed, a crab on a ledge overhead, a cast in mid-air. Expect: the switch is skipped without error, the serpent takes the hit and is not stunned, the landed bat is hit, the ledge crab is hit, the airborne cast hits what stands below (Task 5).
4. **The F4 doorway.** `new_room_beside` rejects a door whose zone holds any solid and would pick a span 60 px above the floor; no lint sees a spawn or decor in a door zone; a relocated spawn keeps its index. Expect: both door halves end at `to == 320`, nothing stands in any door zone, F4's first pass is still 188 (Task 8).
5. **A life reborn in the Deep.** Expect: the stored kit grants Leap, Wall Cling, Swim and Tremor at level 5, leaves two lineages eligible with the seeds and more than without, the kit level's XP to the cap is at most the first-evolution areas' total, and the Flooded's and Grotto's per-area pins survive the table refactor (Tasks 7 and 9).

## Wind-up, charge, rest. A stomper's "charge" is a slam: the windup ends in `_slam` and the rest follows. Returns true while the
## charge sequence owns movement.
func _charger_act(player: Node2D, to_player: Vector2, delta: float) -> bool:
	match _state:
		"windup":
			velocity.x = 0.0
			_state_t -= delta
			if _state_t <= 0.0:
				if def.stomper:
					_slam(player)
					_state = "rest"
					_state_t = STOMP_REST
				else:
					_state = "charge"
					_state_t = CHARGE_SECONDS
			return true
		"charge":
			_state_t -= delta
			if _state_t <= 0.0 or _blocked_ahead():
				_state = "rest"
				_state_t = CHARGE_REST
				velocity.x = 0.0
			else:
				velocity.x = facing * _speed() * CHARGE_MULT
			return true
		"rest":
			velocity.x = 0.0
			_state_t -= delta
			if _state_t <= 0.0:

			return true
	if def.stomper:
		if is_alert() and absf(to_player.x) <= STOMP_RANGE and absf(to_player.y) <= STOMP_LEVEL:
			_state = "windup"
			_state_t = STOMP_WINDUP
			velocity.x = 0.0
			return true
		return false
	var ahead := to_player.x * facing
	if is_alert() and absf(to_player.y) < CHARGE_LEVEL and ahead > TURN_LOCK_RANGE and ahead <= CHARGE_RANGE:
		_state = "windup"

static func first_time(rooms: Dictionary, creatures: Dictionary, ids: Array) -> int:
	var total := 0

		var foreign := 0
		var rest := code
		for i in 6:

			rest /= 7
			if n > 0:
				v[names[i]] = n

		if n_with >= 2 and n_with > n_without and [total, foreign] < best_key:
